НАСТРОЙКИ БАЗЫ

Общий доступ для всех участников

Укажите URL проекта Supabase и публичный anon key. После сохранения войдите под учётной записью Supabase. Секретный service_role key сюда добавлять нельзя.

1. Создайте проект Supabase.2. Выполните SQL из файла supabase-schema.sql.3. Создайте пользователям учётные записи в Authentication.4. Каждый участник вводит эти настройки один раз на своём устройстве.
